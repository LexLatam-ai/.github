# LexLatam.ai

AI-assisted legal research for Panamanian law.

LexLatam combines legal-document ingestion, structured legal data,
retrieval, citation grounding, and AI-assisted research workflows.

## Engineering

The core application, data pipeline, retrieval infrastructure,
deployment infrastructure, and production services are maintained in
private repositories.

Selected engineering contracts and reusable components are published
here when they can be shared without exposing proprietary application code.

### Public engineering

- **lexlatam-taxonomy** — shared Python/TypeScript legal-document taxonomy,
  generated from a single schema-backed source of truth.
